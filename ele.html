Functions of Html Elements



Site link HTML tags are the building blocks of a web page.

The <html> tag is the root element that contains the entire HTML document.

Inside it, the < head> tag stores metadata such as styles, scripts, and other information about the page, while the <title> tag sets the text displayed on the browser tab.
The <body> tag contains all the visible content that users see on the webpage. Headings in HTML are created using < h1> to <h6>, where <h1> is the largest and most important heading and <h6> is the smallest. The <p> tag is used to create paragraphs of text. A line break can be inserted using the <br> tag, while the <hr> tag creates a horizontal line that separates different sections of content. Links and images are important parts of web pages.
The <a> tag is used to create hyperlinks that connect to other pages or resources, and the <img> tag is used to display images.
Lists can be created using the <ul> tag for unordered (bulleted) lists and the <ol> tag for ordered (numbered) lists. Each item within a list is defined using the <li> tag.
HTML also provides tags for displaying data in tables. The <table> tag creates a table, <tr> defines a row, <th> creates a header cell, and <td> defines a data cell. For collecting user information, HTML uses the <form> tag to create forms, the <input> tag to create input fields, and the `button>` tag to create clickable buttons.

To organize and style content, HTML includes the <div> and <span> tags.
The <div> tag is used to create sections or containers that group elements together, while the <span> tag is an inline container commonly used for styling specific parts of text or content within a webpage.
